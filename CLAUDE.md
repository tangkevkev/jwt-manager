# JWT Manager

## What is this app?

A local-first PWA (Progressive Web App) for managing JSON Web Tokens.

The primary use case is parsing and displaying JWTs in a human-readable format, similar to jwt.io — paste a token, see the decoded header and payload displayed clearly.

Tokens can be saved locally for later reference.

## Constraints

- Runs entirely in the browser, no backend server
- Works offline (no internet connection required)
- No MCP or external integrations — pure frontend only
